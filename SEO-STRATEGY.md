# BLOCKS SEO keyword strategy

This document maps search intent to one primary page so future content remains focused and avoids competing pages targeting the same query.

## Homepage

- Primary topic: enterprise technology solutions
- Primary phrase: enterprise technology solutions
- Supporting phrases: enterprise SaaS platforms, technology consulting, AI workflow automation, digital transformation services
- Search intent: organizations evaluating a broad technology partner
- Conversion path: SaaS brand enquiry, Infra Services page, or Contact page

## Infrastructure Security Services

- Primary topic: enterprise infrastructure security services
- Primary phrase: infrastructure security services
- Supporting phrases: vulnerability assessment, penetration testing, cloud security assessment, web application security testing, API security testing, attack surface management
- Search intent: organizations comparing security assessment and remediation capabilities
- Conversion path: security enquiry or free vulnerability assessment

## Contact

- Primary topic: contact BLOCKS technology services
- Primary phrase: contact BLOCKS
- Supporting phrases: SaaS product enquiry, infrastructure security consultation, vulnerability assessment enquiry
- Search intent: visitors ready to speak with the appropriate team
- Conversion path: email, telephone, WhatsApp, LinkedIn, or dedicated SaaS brand email

## Content rules

- Give every indexable page one unique primary topic, title, meta description, and H1.
- Use the primary phrase naturally in the title, description, opening copy, and at least one relevant heading; do not repeat it mechanically.
- Link descriptive words to the most relevant destination instead of using generic labels such as “learn more.”
- Add a separate page only when the subject has distinct search intent and enough useful original content.
- Keep claims specific and supportable. Do not invent certifications, customers, locations, guarantees, or performance statistics.
- Review search-query data in Google Search Console before changing target phrases.
